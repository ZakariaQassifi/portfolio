## About this website

The site is a **neo-brutalist terminal-themed** portfolio: everything is styled like console windows/"green-screen" terminals sitting on a blueprint grid, with hard shadows, thick ink borders, stickers and marquee accents.

### Features

- **Light & dark themes** (light is the default) with a persisted toggle (`localStorage`).
- **Interactive particle background** on a full-page canvas.
- **Zexter chat terminal** — a terminal-style contact section with a friendly bot that shares email, phone, GitHub and LinkedIn.
- **CV modal** that links to the full PDF on Google Drive.
- **Scroll reveal animations** and hover interactions.
- **Accessibility**: skip-to-content link, focus-visible outlines, screen-reader labels, `aria-live` chat region, semantic HTML.
- Fully responsive (desktop → mobile).

### Tech stack

- Semantic **HTML5**
- Custom **CSS3** (CSS variables theming, gradients-based blueprint grid, keyframe animations)
- Vanilla **JavaScript** (theme persistence, particles, chat bot, modals, reveal-on-scroll)

## Running it

No installation needed — it's a static site. Just open `index.html` in a browser, or serve it locally:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```
